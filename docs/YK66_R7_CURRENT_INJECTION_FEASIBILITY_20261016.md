# YK66 R7 二端子・一枚AC100V基板の理想注入電流スクリーニング（2026-10-16）
**状態：数式検証PASS、実回路/部品/PCB未完成、FAB/商用AC100V通電HOLD。**

## 固定要件
最初からAC100V 50/60Hzの単一PCB。低電圧専用PCBを別途製作しない。L–N二端子並列・差動能動ノイズ低減、独立ハード保護、最初の一台3,500円目標（未見積）。RC18-FULLは変更せず、S1、HF19、E50、P14/P15の検証方法と失敗条件を再利用。

## 過去P15の課題と本計算の位置
R5で確認したP15の候補15件は全件1–5kHzの増幅領域を持ち、Rs/Rl 9組の全条件を合格したものは0件。既存候補をそのまま基板化しない。
R7では「10kHz、3dB減衰にどれだけの電流が必要か」を、**純抵抗型 Norton 等価モデル**で先に数値化した。実源/負荷は複素数であり、この数値は物理回路の合否判定でも安全定格でもない。

## 理想式
Zp=Rs||Rl、V_on/V_off=1/(1+Zp*Y)（正の実数Y）。
目標A=3.0dBの場合、Y=(10^(A/20)-1)/Zp。
任意の比較入力 V_off=100mV peak のとき、必要な注入電流の絶対値 I_peak=V_off*(1-10^(-A/20))/Zp。
100mV peakは**仮定した雑音振幅**であり100Vrms商用電源の波形振幅ではない。

R5/P15の比較条件「100Vrms 50/60Hzで1mA以下」を暫定採用すると、|Y(50/60Hz)|≦10μS。他方、10kHzに必要な最大Yは約4.208S。要求されたアドミタンスの大きさは周波数間で約420,788倍（112.48dBの比）。**112.48dBはノイズ減衰性能を意味しない。** 実部品の位相、寄生、電流制限、発熱、過渡、安全性は未検証。1mAも法規上の限界を意味しない。

この計算はローカルの標準Python計算スクリプトと6件の単体テストで再現済み（6/6 PASS）。プログラム、テスト、9条件CSV、詳細説明はR7成果物ZIPにまとめた。
