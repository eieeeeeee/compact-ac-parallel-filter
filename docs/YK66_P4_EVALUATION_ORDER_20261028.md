## 発注前の未解決点: J1公差
Phoenixは穴径1.3mm、ピン0.9×0.9mmを記載。JLCPCB公式能力表（今回閲覧）は一般スルーホール径+0.13/-0.08mm、穴位置±0.075mmを記載。
- 仕上がり穴の下限1.22mmは、0.9mm角ピンの理論対角1.273mmより小さい。ピン角の丸み・現品公差を含む挿入保証は未確認。
- 単純化した最悪残銅リングは(2.04-1.43)/2-0.075=0.230mm。銅箔加工公差等は含まず、メーカーの正式DFM判定を代用しない。
- 既存2026-10-25検討は位置公差±0.05mmを仮定し0.255mmと計算していた。今回の公式ページ値を用いると0.230mmに変わる。
- 製造業者の実注文条件と現物端子で挿入成立を確認する。入らない場合、めっき穴を現物で削って通電用へ転用せず、基板改版と再検証を行う。
- 変更なしで進める場合は、まず機械嵌合を確認する評価ロットとして扱う。穴径・ランドを変更する場合は新しい基板IDとDRC・出力検査を必要とする。
