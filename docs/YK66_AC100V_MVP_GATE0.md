## 製品目的と不変要求
- **実使用条件: 日本の商用AC100 V、50/60 Hz。**
- **接続形態: L–N間の並列接続。** 負荷電流を直列に通すフィルターではない。
- **機能: RC18から継承する能動的な伝導ノイズ抑制。** 単なるX2コンデンサによる受動フィルターは、別の比較用回路とし能動YK66の完成代替にはしない。
- **初号機1台の目標原価: PCB製造 + 部品 + 実装 = 3,500円以下。** ステンシル代は除外。これは未達・未積算の目標であり、保護省略の理由にしない。プラグ・ケース・規制試験等が含まれるかは別途総費用として明示する。
- **動作確認の定義: 実物の基板・筐体で、安全審査を経てAC100Vにおける同一条件のON/OFFノイズ測定結果が出た状態。** GitHub CI成功、SPICE、KiCad DRC合格、LED点灯は完成とは扱わない。

## Gate 0: 回路アーキテクチャを固定するための必須ブロック
1. **AC入力/一次側保護:** 定格に適合した密閉接続部、上流ヒューズ、異常温度/サージ保護。部品組み合わせと故障時挙動は認定資料・保護協調試験で確定。
2. **電源:** AC100V対応の安全認証情報を持つ絶縁AC/DCモジュールを優先候補。例: MEAN WELL IRM-01-3.3 (3.3V/1W)。制御用3.3Vだけでは、RC18既存の12V注入段を駆動できない。**注入段の電源方式と絶縁境界は未決定**であり、単純に直結しない。
3. **測定/制御:** 既存RC18の検証済み信号処理・MCU・制御アルゴリズムを再利用候補とする。電源ライン検出、ゼロ交差、測定機器の接地、ADC入力保護および一次二次間絶縁を別途設計審査する。
4. **注入段:** AC L–N間でノイズ成分を打ち消す能動注入経路を設計。**X2定格部品の採用だけで注入段全体が安全になるわけではない。** 結合方式、一次二次間バリア、許容電流、故障時の分離、逆流、SOA、電源断時の状態を独立に確認する。
5. **ハードウェア独立保護:** ファームウェアとは独立した過電流遮断、ハードラッチ/フェイルオフ、起動禁止、過温度・短絡/接点監視。シングルフォールトで発火や危険な露出が生じないことを安全レビューで示す。
6. **機構/絶縁:** 難燃ケース、保護接地要否、沿面・空間距離、過電圧カテゴリ、汚損度、絶縁種別、ヒューズ近傍の温度/アーク影響、コンセントプラグの力学強度を対象規格から導出する。根拠のない固定mm値を採用しない。

## 実現性に関する現時点の判定
- 100V用の受動並列ノイズ吸収ネットワークと、RC18型の**能動**注入回路は別物。前者だけを作って後者の動作実証と称しない。
- 前提となるAC100V注入結合回路と絶縁/保護協調を未設計・未検証。したがって**AC100V動作・3,500円達成・減衰性能はすべて未達**。
- 既存のKiCad10 ERC 0 / DRC 0 / Unconnected 0 / parity 0 (R2.3.1C) はその候補の設計整合性に限定する。AC100V対応や製造/電気安全を保証しない。
- 市販のAC/DCモジュール参考: IRM-01-3.3 はAC85–305 V入力、3.3 V・1 W、参考単価約817円/個（税抜、DigiKey掲載例。購入時再確認）。12V注入出力段が必要なら別電源または代替アーキテクチャが必須。**3,500円以内の正確なBOMはまだ確定できない。**
- メーカー参考: TDK/EPCOSの認証X2コンデンサはライン間のEMI抑制用途に使われるが、選定は認証・定格・故障解析で別途確定。
- 国内適用法令: PSE該当性/電気用品分類・規制対象を経産省へ製品仕様に基づいて確認する。個人試作/販売の可否は製品の分類・接続方法等に依存するため、この文書で断定しない。

## 最短開発経路（安全ゲート順）
**A.** RC18合格候補を凍結し、100V側保護・絶縁方式・能動注入方式の電力/故障シミュレーションを作る。AC100Vを模擬するモデルはまず無通電で検証する。

**B.** 実装候補の部品・フットプリント・サプライヤーデータシートと原価を紐付ける。コストが3,500円を超える場合、**過電流/絶縁保護は減らさず**アーキテクチャ側の部品点数を見直す。実装費・発注最小額・送料・ケース・プラグは別欄に可視化。

**C.** Native KiCad 10.x の ERC/DRC/netlist parity/未接続、メーカーpinout、部品定格、絶縁バリア、単一故障の整合性をチェック。**すべてPASSまで製造用データのリリースを止める。**

**D.** 実機の試験: 無通電確認→低電圧の制御/ハード遮断テスト→専門の試験環境でのAC100V試験。適切な測定治具・プローブ・安全設備と資格/技能を有する担当者による実施。安全レビュー前のコンセント直挿しをしない。

**E.** 同一源インピーダンス・LISN/擬似電源回路・同一負荷条件で、非装着/装着の伝導ノイズを測定し、5–30kHz・30–700kHzの改善量と悪化量を公開。改善ゼロや悪化も隠さない。ユーザーが求める競合比較は実測比較後に限定。
