# YK66 R6 — 原価・製造容易性優先の設計方針（2026-10-16）

## 決定と適用範囲
ユーザー指示により、**費用と作りやすさを最優先**し、その次にノイズ低減性能（dB）を最大化する。優先順位：
1. **安全成立（削れない絶対条件）**：AC100V 50/60Hz、単一故障を想定した独立ハード保護、適切な絶縁・定格・放電・サージ・クリアランス／沿面距離。安全をコスト削減の犠牲にしない。
2. **初回1台の総額と製造容易性**：部品、PCB、組立、初回セットアップ費、送料、税を含む **3,500円以内**（ステンシル代のみ除外）を目標。費用達成は**未検証**。独自実装、手半田困難な部品、特殊工程、調達難品を避ける。
3. **広帯域で悪化させず成立する基本性能**：二端子・端子電圧のみで制御可能な L–N 差動ノイズ低減。まず 10kHz の OFF–ON–OFF 再現測定で **3dB以上**、測定帯域の増幅 **+0.5dB以内**を初期ゲートとする（実測未達）。性能向上はこの後。
4. **性能余力（高dB）は最後に探索**：過去RC18 S1の47〜54dBは別モデルの計算結果であり、YK66実機の保証値ではない。50dBは野心目標であり、原価・製造・安全の基本ゲートを犠牲にしない。

## 一枚基板・一系統の設計ルール
- **AC100V対応の完成品を意図する単一PCB**に、端子検出、ノイズ低減、電源、制御、独立ハード保護を統合する。低電圧専用の別製品基板を先に作らない。ただし一枚目の改版可能性までゼロとは約束しない。
- 部品選定は **標準で入手可能・少点数・自動実装しやすい・定格明確**を優先。複雑な高性能MCU、GaN、高速ADC/DACを必須にしない。アナログ連続時間制御＋単純な監視を第一比較候補とし、機能・安全・安定性・費用が裏付けられた場合に限り高度な制御を追加する。
- **安価なドライバにしても必要注入電流が減るわけではない**（P8〜P10）。二端子制約と低い源インピーダンスを織り込み、実部品の電流・発熱・位相安定性が成立しない案は部品購入前に除外する。
- P15の15候補は、1〜5kHz増幅および9つの源負荷条件の不合格があるため**そのまま採用しない**。旧計算は探索範囲・失敗条件・検証コードとして再利用する。
- **独立保護を後付けしない**。E34〜E50で見つかった安全部品欠落、DNP/FIT矛盾、論理無効、銅島断線、部品定格問題を製造リリースの停止条件に使う。

## 選定フロー（R6へ適用）
1. 過去の原本を凍結して出典を明記し、**候補回路は1つの主案に絞る**。複数基板を並行制作しない。
2. **最初に安全・原価・実装性の3ゲート**：独立保護、調達可能な実在部品の定格とフットプリント、初回1台の全費用内訳。見積りなしの数値は実績と呼ばない。
3. 主案に対し実部品GBW・電流上限・消費電力・1〜5kHz増幅・5〜30kHz減衰・30〜700kHz過大増幅・9組インピーダンス・50/60Hzを回路解析で評価。閾値未達なら基板発注に進まない。
4. 同じ主案から Native KiCad 回路図→PCB→ ERC0/DRC0/未接続0/BOM↔CPL↔フットプリント一致→独立安全審査。これらが揃うまでは **FAB HOLD / MAINS HOLD**。
5. 実機は独立した適切な試験設備・専門家監督の下で検証。計算PASSと100V安全・性能実証を混同しない。
