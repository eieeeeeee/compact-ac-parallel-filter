# YK66 R6 — AC100V 二端子・一枚基板の統合設計基準 (2026-10-16)

**ステータス: Architecture baseline / 回路未完成 / PCB未配線 / 実機未製作 / 100V通電HOLD / Gerber製造HOLD.**

## 最終目標とユーザー確定要望
- 最初から **日本のAC100V 50/60Hz用の単一PCB**を設計する。低電圧用専用PCBを先に作り直す二重開発はしない。
- コンセント二端子 L–N の差動モード、電源線への **並列接続** で能動的に5〜30kHzのノイズを減らす。30〜700kHzと1〜5kHzでの増幅を監視する。共通モードは保証範囲外。
- PCB、部品、初回一台実装と製造・送料・税を含め **3,500円以内（ステンシル代除外）**を目標。現状未見積、未達成。安全機能は削減しない。
- 「最初から一枚の完成品構成」と「最初から100V通電できる」は異なる。基板を発注する前に回路安全審査、解析、部品証拠が必要。作った後も独立保護を検証し、専門的環境で通電する。

## 一枚PCB内の機能分割（物理的には同一PCB）
1. **L–N AC入力・保護** — 商用定格の過電流/サージ対策、放電、異常時の独立ハード遮断経路、故障時に安全側へ倒す状態。安全部品型式・配線の採用は未承認。
2. **絶縁電源** — 制御・検出・ドライバーへの必要電源、起動/低電圧故障/復帰時の安全OFF。候補IRM-03-12は外部電源候補のみで、装置全体の安全認証にはならない。価格/面積に適合するか未定。
3. **二端子で測れる端子電圧の検出** — P13の上流センス点を一切仮定しない。電位差、絶縁、入力過渡、ノイズ耐量を回路設計で要決定。
4. **有限能力を持つノイズ打消し電流生成とL–N結合** — P14/P15の周波数選択シャント概念から実在するアンプ/ドライバー/結合部へ写す。GBW、位相余裕、電力、熱、飽和、電流限界、50/60Hz遮断と過渡の評価が必須。X2定格だけを能動電流注入の絶縁証拠としない。
5. **独立安全判定・遮断と状態監視** — コントローラが暴走しても保護系単独で出力停止できる。過電流、過熱、センス喪失、制御停止、起動不良を検知。RC18 S4/S4.1のロジックは安全管理テストの参考でありハード独立保護の代替ではない。

## 一枚で作れる設計にするための実務優先度
- **G0: 物理回路選択が最優先（未達）**。二端子検出、実用的な電流生成/結合、ゲイン/帯域/位相余裕、P15全15候補が失格になった源・負荷変動を含めて最低一案を確認する。設計が成立しないまま基板の配線は始めない。
- **G1: 同じ最終100V設計をシミュレーション**。50/60Hzの定常応力と高周波雑音の伝達・過電流/短絡/断線/サージをモデル化。試験用に別PCBを新設しない。安全評価に必要なら最終PCB上の試験端子または隔離された検証治具を設計する。
- **G2: 安全設計エビデンス（未達）**。部品の電圧/電流/熱定格、絶縁、沿面/空間距離、ヒューズ協調、サージ、接点溶着や故障時OFF、使用筐体、PSE該当性を有資格者/専門家が査定。
- **G3: 単一KiCad nativeプロジェクト（未作成）**。回路図と1枚PCBの結合。原本SHAごとのERC/DRC/未接続/parity、実装・部品型式/BOM/CPL/Gerberを追跡。旧版PASSは流用しない。
- **G4: 1台の実見積（未達）**。安全保護を全て含めPCB/部品/初期SMT実装/送料/税を確定。3,500円超過なら再設計か目標見直し（安全除外禁止）。
- **G5: 試験（未実施）**。同じ一枚PCBを使い、まず絶縁・電流制限の試験環境で設計検証する。安全試験に合格した後に初めて専門試験設備で100V通電。物理試作は原則一種類だが、不具合時の改版は必要になる。

## 最低性能の目標と判定
- 初期実測ゲートは10kHzでOFF–ON–OFFを3反復し、同条件の実測ノイズ低減 **3dB以上**。
- 5〜30kHzを評価し、1〜5kHzと30〜700kHzで増幅を監視。測定済み点での悪化 **+0.5dB以下**を暫定基準（未測定点は不明）。
- 源/負荷インピーダンスの変動に耐えること。50/60Hz定常漏れ/無効電流・発熱・短絡など安全上の条件は性能以上に優先。
- 50dBは旧モデルでの参考値でありR6の約束値ではない。3dB初期ゲートで「製品完成」とはしない。
