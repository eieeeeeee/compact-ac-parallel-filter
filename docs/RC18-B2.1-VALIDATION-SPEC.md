# RC18-B2.1 Validation Specification

Status: **simulation-gate candidate**  
Date frozen for this validation package: **2026-09-23**

## Scope

This specification freezes the electrical simulation gate for RC18-B2.1. It is a low-voltage architecture study and does not specify a safe AC-mains sensing, coupling, isolation, enclosure, protection, or certification solution.

## Frozen architecture

| Parameter | Frozen value |
|---|---:|
| Power stage | EPC23104 |
| PWM carrier | 3.000 MHz |
| Control update | 2.000 MHz |
| Total modeled deterministic latency | 2.041 µs |
| Bounded jitter | ±25 ns |
| L1 / C1 | 0.82 µH / 150 nF |
| L2 / C2 | 0.47 µH / 100 nF |
| L3 / C3 | 0.68 µH / 82 nF |
| Active-current ceiling | 120 mArms |
| Command ceiling | 3.39411255 Vrms |
| Watchdog limit | +0.500 dB vs passive-only |

The total latency is a model parameter. It is not a claim that any particular MCU path has already been measured at exactly 2.041 µs.

## Digital controller

```text
H(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2)

b0 =  1.96005549
b1 = -2.81840199
b2 =  0.92560172
a1 = -1.02969083
a2 =  0.09694605
Fs = 2.000 MHz
```

The repository validates both sequential float32 arithmetic and a CMSIS-style Q31 Direct Form I model.

## Frequency and line-condition grid

Primary band:

- 241 logarithmically spaced points from 5 kHz to 30 kHz.

Watchdog band:

- 241 logarithmically spaced points from 30 kHz to 100 kHz.

Source grid:

- |Z| = 0.2, 0.5, 1, 2, 5, 10, 20 Ω
- phase = −60°…+60° in 15° steps

B2.1 component corners:

- nominal
- low: L = −20%, C = −20%
- high: L = +20%, C = +5%

## Same-model RC17 references

The strict equivalence gate compares RC18 against the same-model RC17 fine-grid references:

| |Z| | RC17 worst 5–30 kHz |
|---:|---:|
| 0.2 Ω | −0.2636906885 dB |
| 0.5 Ω | −0.7091844043 dB |
| 1 Ω | −1.6667104947 dB |
| 2 Ω | −3.2910560941 dB |
| 5 Ω | −7.1912637526 dB |
| 10 Ω | −11.4569605355 dB |
| 20 Ω | −16.4968118447 dB |

These values are comparison references inside this disclosed model. They are not measured attenuation values.

## Required gates

A candidate passes only if all tested corner/Z cases satisfy all of the following simultaneously:

1. worst 5–30 kHz result is no worse than the frozen same-model RC17 reference;
2. maximum 30–100 kHz worsening vs passive-only is ≤ +0.500 dB;
3. active current is ≤ 120 mArms;
4. command is ≤ 3.39411255 Vrms;
5. modeled active admittance remains non-negative in real part over the modeled grid;
6. the same selected G survives −25 ns, nominal, and +25 ns timing cases.

## Reproducibility

Run:

```bash
python -m pip install -r simulations/rc18-b2.1/requirements.txt
python simulations/rc18-b2.1/validate_rc18.py
```

The script exits with status 1 if any required gate fails. This is the same command used by GitHub Actions.

## What this gate does not prove

Passing this gate does not prove:

- mains safety;
- PSE/IEC/UL compliance;
- radiated or conducted EMC compliance;
- EPC23104 thermal performance on the final PCB;
- real inductor core loss at 3 MHz;
- stability with an arbitrary real household impedance spectrum;
- real-world noise reduction before physical measurement.
