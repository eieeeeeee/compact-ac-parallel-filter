# RC18 / YK66 — 2026-09-20以降の資産を活かす R4 開発引き継ぎ

作成: 2026-10-16 JST / 状態: **資産照合・理想モデル再評価。実機未製作、商用AC100V通電とGerber製造はHOLD。**

## 最も重要な設計判断
**YK66は二端子のAC100V・50/60Hz・L–N並列・差動モードの能動ノイズ低減装置。** まず独立電源の12V以下の試験治具で二端子シャントの成立を調べ、安全審査とAC100V用絶縁/保護を通過したときに商用接続版を試作する。初回1台のPCB+部品+実装3,500円（ステンシル除外）は目標であり、達成を確認していない。RC18-FULLの50×40mm凍結MASTERは変更しない。

### なぜ重要か
- YK66 P13は**ノイズ源上流を検出できる**仮想治具で5kHz 46.78dB、30kHz 31.22dBという計算。しかしコンセント二端子の外側から上流の基準点へアクセスできないので、同じ制御を移植できない。
- P14で二端子の端子電圧センシング＋制御シャントアドミタンス方式を検討開始。1Ω源・10Ω負荷で理想50dBを狙うのに約346.75S（約2.88mΩ）という非常に大きなアドミタンスが必要。安全な小型装置に厳しい。
- P15：324個の理想シャント伝達モデルをLibrary元CSVから独立再集計。5/10/30kHzの最小減衰≥3dB、モデル5–700kHzの悪化≤0.5dB、100Vrms 50Hzの仮想シャント電流≤1mAという条件に21件該当。この21件のうち60Hzでも≤1mAなのは15件。**6件は50Hzのみで、60Hzでは不適合**。両周波数を検査すること。
- P15の理想シャント電流源は、実際の電源回路・opamp・MOSFET・絶縁結合部品・独立過電流保護・負荷インピーダンス変動を実装していない。選定結果を実機合格とみなさない。
- R3の10kHz約6.01dBは10Ω/10mAの**別の理想化モデル**。P15の実用二端子モデルと混ぜたり、複数のdB値を足したりしない。
- 9月20日のwall_filter v0.4→v0.5でKiCad DRC 28→0の記録や1MHz/50Ω/理想1µFの約50dBは**別条件**。商用AC100Vで5–30kHzを50dB下げた証明ではない。

## ゲート（先へ進むための証拠、現状すべて製造HOLD）
1. **G0・接続モデル**: 二端子で実装可能な端子電圧センシングとアドミタンス実現方式を、源/負荷の複素インピーダンス変動を含めてモデル化。5–30kHz, 30–700kHz、50/60Hzで測るべき量を固定。理想的な高アドミタンスを実電力段へ短絡的に写さない。
2. **G1・実部品ELV試験**: 独立絶縁・電流制限のある12V以下の治具で10kHz、OFF–ON–OFF３反復、実測3dB以上、測定周波数での悪化≤0.5dB、危険な発振/異常発熱なし。低電圧のハードウェア独立遮断を実測。
3. **G2・AC100V回路の専門的安全審査**: L–N注入結合の50/60Hz、サージ、短絡、溶着、隔離バリア破壊、放電、漏れ電流、筐体、PSE該当性等について、安全規格と部品メーカー資料に基づくレビュー。**市販品の電源モジュールだけでは製品全体を承認できない。**
4. **G3・原価**: 1台分PCB+全部品+SMT組立の実見積で3,500円以内。無理なら保護部品を省略せず方式/価格目標を再検討。ステンシル除外の定義を維持。
5. **G4・Native KiCad10 / 完成版でERC0/DRC0/Unconnected0/parity0**: 原本 SHA256 とプロジェクト識別を固定。回路とPCB、部品MPN、FIT/DNP、購買/フットプリント、製造用出力一致を毎回照合。
6. **G5・管理されたAC100V実証**: G2–G4に合格後、専門家の試験環境でAC100V/50–60Hz時のOFF/ONの差動ノイズ・熱・短絡時の保護を記録。50dB達成・競合比較は**同じ負荷/測定回路/帯域/ノイズ床**の実測に基づき判定する。
